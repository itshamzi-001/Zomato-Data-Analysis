# Zomato Data Analysis Using Python

## Project Overview

This project performs exploratory data analysis on a Zomato restaurant dataset using Python.

The analysis explores restaurant types, customer votes, online ordering, ratings, approximate cost for two people, and ordering preferences.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data loading and exploration
- Data cleaning
- Restaurant type analysis
- Votes by restaurant type
- Most voted restaurant
- Online order availability
- Rating distribution
- Approximate cost for two people
- Online vs offline rating comparison
- Restaurant type vs online order analysis

## Key Skills

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Aggregation
- Data Visualization
- GroupBy
- Pivot Tables
- Statistical Visualization

## Dataset

Zomato restaurant dataset used for educational and analytical purposes.

## Conclusion

This project demonstrates the use of Python libraries to explore restaurant data and extract meaningful insights through data analysis and visualization.
